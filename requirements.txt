# Emissium — зависимости и требования к окружению
# Проект использует JavaScript / Node.js. Python-зависимостей нет.
# Это справочный список npm-пакетов, а не файл для pip install -r.
# Установка из корня проекта: npm ci
# Установка серверных зависимостей из корня проекта: npm --prefix server ci
# Точные версии ниже взяты из соответствующих package-lock.json.
# Полное дерево зависимостей фиксируется в lock-файлах.

# Окружение
# Рекомендуется Node.js 24.x; также подходит Node.js 22.x.
# React Router 7 и better-sqlite3 12 требуют как минимум Node.js 20.
# Менеджер пакетов: npm (поставляется с Node.js).
# SQLite работает через better-sqlite3, отдельный сервер БД не требуется.
